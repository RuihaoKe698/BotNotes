# BotNotes

BotNotes 是一个常驻屏幕顶部的 Markdown 笔记工具。平时它是一个会眨眼的小机器人，点一下展开成笔记面板，点别处就收起。

## 它能做什么

- **随手记**：点小机器人展开面板，输入 Markdown，停止输入后自动保存。
- **直接改文件**：每个标签就是一个真实的 `.md` 或 `.txt` 文件。BotNotes 改的就是那个文件，不导入，不复制。
- **预览里直接修改**：在排版好的预览里点任意一行就能改，可以勾选待办、折叠标题。
- **脑图**：按 Ctrl+M 把当前笔记画成脑图。脑图可以直接编辑，可以导出图片，也可以全屏逐步演示。
- **历史版本**：自动保留快照，删错了可以找回。
- **保持唤醒**：点咖啡杯后电脑不自动睡眠，合上盖子也继续运行。
- **干净桌面**：点一下收起桌面图标并换成纯色背景，方便录屏；再点一下恢复。

完整的操作说明见 [使用说明.md](使用说明.md)。

## 下载和安装

1. 在[发布页](https://github.com/RuihaoKe698/BotNotes/releases/latest)下载 `BotNotes-版本号.zip`。
2. 解压到任意文件夹。
3. 双击 `BotNotes.exe`。

BotNotes 不需要安装，也不需要管理员权限。

### 第一次打开时的提示

BotNotes 没有购买代码签名证书，所以 Windows 第一次打开时会显示“Windows 已保护你的电脑”。点“更多信息”，再点“仍要运行”即可。这个提示只出现一次。

浏览器下载时如果提示“不常下载的文件”，选择“保留”。

想确认下载的文件没有被改过，可以核对发布页上的 SHA256：

```
certutil -hashfile BotNotes-版本号.zip SHA256
```

系统要求：Windows 10 或 Windows 11。程序使用系统自带的 .NET Framework 4.8，不需要另外安装运行库。

## 上手

1. 点屏幕顶部的小机器人，展开面板。
2. 输入内容。第一行是这篇笔记的标题，也是文件名。
3. 按 Esc 或点别处收起。

新建的笔记默认保存在“文档\BotNotes”，可以在“设置 → 保存位置”里改。

## 升级

BotNotes 不会自动检查更新。在“设置 → 关于”里点“查看新版本”，下载后退出旧版，用新的 `BotNotes.exe` 替换旧的。笔记和设置都保留。

## 隐私

BotNotes 不联网，也不收集任何信息。笔记是你电脑上的普通文件，设置和历史快照保存在 `%LOCALAPPDATA%\BotNotes`。

## 会改动的系统设置

下面三项功能会改动系统设置，都只在你打开对应开关时生效：

- **开机自动启动**：在当前用户的启动项里添加 BotNotes。
- **保持唤醒**：把当前电源方案的“合上盖子时”改成“不采取任何操作”。关闭开关或退出程序时恢复原值。
- **干净桌面**：隐藏桌面图标，并按设置更换背景色。关闭开关或退出程序时恢复原状。

程序意外退出时，下次启动会先恢复后两项。

## 已知限制

- 面板只在主显示器上显示。
- 界面只有中文。
- 还不支持读屏软件。
- 预览不显示图片。

## 反馈问题

在[反馈页](https://github.com/RuihaoKe698/BotNotes/issues)提交问题。程序出错时会把记录写进 `%LOCALAPPDATA%\BotNotes\logs\crash.log`，请把这个文件一起附上。“设置 → 关于 → 出错记录”可以直接打开这个文件夹。

## 从源码编译

需要 .NET SDK。

```
dotnet build BotNotes.sln -c Release
dotnet test BotNotes.sln -c Release
```

`build.cmd` 会编译并把 `BotNotes.exe` 复制到仓库根目录。`release.ps1` 会编译、测试并打出发布包。
